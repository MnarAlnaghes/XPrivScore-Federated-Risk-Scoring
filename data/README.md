# Datasets

Download each dataset from its public source and place the files here
with exactly these names:

| Dataset | Files | Source |
|---|---|---|
| ULB Credit-Card Fraud | `creditcard.csv` | https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud |
| IEEE-CIS Fraud Detection | `train_transaction.csv` | https://www.kaggle.com/c/ieee-fraud-detection |
| Elliptic Bitcoin | `elliptic_txs_features.csv`, `elliptic_txs_classes.csv` | https://www.kaggle.com/datasets/ellipticco/elliptic-data-set |

The datasets are not redistributed in this repository.
